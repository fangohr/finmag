# Status of this directory

**Superseded.** This is the legacy Sphinx documentation tree, frozen around
2018 and written for the Python-2 / `dolfin` 2017 codebase. It is not built
by any current CI workflow and is not maintained.

It is kept in place for historical value, not as a source of current
instructions — some of it may be outdated or inapplicable to the current
`dolfinx-parity` branch.

**Live, current documentation is in [`../docs/`](../docs/README.md).** Start
there: [`../docs/SUPPORTED.md`](../docs/SUPPORTED.md) for what works today,
[`../dolfinx-transition.md`](../dolfinx-transition.md) for the port story.
